# Screenshots

Game screenshots show Root 2.1.5 running the six-player mod on Linux through Proton.
These are unedited captures from local automated tests, not remote multiplayer sessions.

| File | Capture |
| --- | --- |
| `board.png` | Mountain map with six factions, including two Vagabonds. Resumed test checkpoint, 1920 × 1080, September 27, 2026. |
| `settings.png` | Native private-game settings, 1280 × 800, September 27, 2026. This test simulated expansion ownership. |
| `launcher.png` | Native Go startup window, 800 × 500, September 29, 2026. Loads artwork from the local Steam cache and the font from Root's installed files. Captured on an isolated Xvfb display without starting Root. |
